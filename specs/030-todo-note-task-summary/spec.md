# Todo 笔记插入任务摘要规格

**Issue:** 见 PR `Fixes #…`
**状态：** 已实现待合并（本地六项门禁全绿；矩阵 #89 行状态只在 PR 合并后翻）。

## 目标

把嘀嗒的「摘要」搬到 Flutter 端唯一事实来源：对**一段时间内的任务完成情况**生成可编辑文本，并插入笔记正文。
嘀嗒帮助中心 `03-特色功能/11-笔记与摘要.md:206` 定义它服务于日报/周报，`:239` 明确
「移动端有且只有『笔记』支持添加摘要」，因此入口落在笔记编辑器，不落侧栏。

摘要文本由本地 Drift 任务数据**确定性**生成：不调用任何接口、不含 AI。

## 可验收行为

- 笔记编辑器提供 `插入摘要` 入口；确认后摘要出现在光标处，草稿原有文字保留；取消则草稿逐字节不变。
- 摘要预览可选：时间区间（今天 / 近 7 天 / 近 30 天 / 本月 / 自定义起止，自定义走日期范围选择器，
  取消选择就保持原区间不变）、清单（多选，空=全部）、
  状态（全部 / 仅已完成 / 仅未完成）、分组（不分组 / 按清单 / 按完成状态）、排序（时间 / 标题）、
  显示更多（完成日期、进度）。预览所见 = 插入所得。
- 区间归属规则（唯一口径，写进实现与测试）：已完成任务按 `completedAt` 落入区间；
  未完成任务按 `dueAt` 落入区间，无 `dueAt` 时按 `createdAt`；`cancelled` 任务任何档位都不进摘要；
  **子任务不单独成行**（`parentTaskId` 非空即排除，与任务列表口径一致），只计入父任务的进度。
- 「进度」优先取检查事项 `done/total`，无检查事项时取子任务 `done/total`，两者皆无则不输出进度片段。
- 摘要标题里的区间必须描述**实际取到的数据**：区间切换后取数中或取数失败时，预览仍标注上一次成功的区间，
  且此时禁止插入，避免把旧数据当新区间的结果用。
- 区间内没有任务时，预览显示 `该区间内没有任务`，`插入` 按钮禁用；不得插入空摘要或占位符。
- 同一输入必须产出逐字节一致的文本：组内排序以选定字段、`sortOrder`、任务 UUID 为次序键。
- 未登录或本地库不可用时显示可读原因并禁用插入，不显示假预览。
- 320px 视口 + 1.3 倍字体不溢出；选项与按钮具备独立可读屏语义；刷新失败保留上一次已加载数据；
  过期响应不得覆盖新响应。
