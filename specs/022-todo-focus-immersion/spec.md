# Todo 番茄沉浸模式

**状态**：设计完成
**创建日期**：2026-08-02
**关联 Issue**：[#253](https://gitea.zh04.com/izhaong/zh-cloud-todo-flutter/issues/253)
**上游规格**：`specs/015-todo-focus-session-parity/`

## 背景

滴答清单“如何保持专注状态”支持在已开始专注时进入沉浸界面，并切换简约数字、翻页钟和像素时钟；用户可设置自动进入沉浸模式。当前 Flutter 的 `PomodoroPage` 保留完整计时状态机，但只呈现普通工作区，未提供沉浸入口、样式或自动进入偏好。

参考：[如何保持专注状态](../../../zh-cloud-docs/todo/99_参考资料/dida365-help-center/02-功能指南/04-番茄专注/02-如何保持专注状态.md)。

## 需求

- **FR-001**：仅在存在 RUNNING 或 PAUSED 专注会话时，普通专注页的更多操作中可手动进入沉浸模式；没有会话时不得出现误导性的进入入口。
- **FR-002**：沉浸模式必须复用同一会话、计时器和服务端动作。用户能明确执行暂停/恢复、完成、取消和退出沉浸；退出只改变展示，不暂停、取消或完成专注。
- **FR-003**：沉浸模式提供 `digital`（简约数字）、`flip`（翻页钟）和 `pixel`（像素时钟）三种可见且可读屏的计时样式。切换样式不重置秒数、不改变会话模式，也不发起专注 API 写操作。
- **FR-004**：提供“自动进入沉浸模式”偏好。它是当前设备的展示偏好，使用 `shared_preferences` 持久化；已开启时，新开始或重新同步得到的活跃会话在偏好加载完成后自动进入一次。用户手动退出后，本会话不得因 15 秒同步轮询重复弹回沉浸界面。
- **FR-005**：沉浸界面默认隐藏操作层；点击/轻触计时区域可显示或收起操作层。操作层的每个动作均有稳定可见文字、tooltip 和语义名称，键盘可聚焦并可执行。
- **FR-006**：沉浸模式在 320px 宽度、较大文本缩放和 Web/桌面窗口下不得横向溢出；会话被另一端完成或取消后，必须退出沉浸并回到普通专注页面，不保留过期动作。
- **FR-007**：本切片不新增、修改或模拟 Pomodoro Service API、会话 DTO、Drift 表、outbox 或同步载荷；展示偏好不得冒充跨设备专注事实源。

## 非目标

- 不在本切片实现白噪音或播放音频；该能力需要带许可证的音频资产和跨平台播放器验证。
- 不在本切片实现屏幕常亮、Android 悬浮窗、翻转开始、严格模式、应用白名单或 iOS Live Activity；它们需要各自的原生插件、平台权限、系统 entitlement 或安全边界。
- 不请求浏览器原生全屏权限；“沉浸模式”是 Flutter 应用内的无干扰展示层。

## 验收

- 红绿 Widget 测试覆盖：无会话不能进入、手动进入、三种样式、计时连续性、暂停/恢复/完成/取消、手动退出不改变服务端会话、自动进入、退出抑制、远端结束收敛及 320px。
- 偏好存储测试覆盖默认值、损坏值安全回退、写入失败不影响当前会话和本会话退出抑制。
- `dart format --output=none --set-exit-if-changed`、`flutter analyze`、受影响测试、全量 `flutter test --concurrency=1` 和 test 配置 Web release 构建均通过。
- Claude CLI 采用已验证的无工具分段 stdin 评审，分别审查存储/状态、沉浸 UI 与测试合同，并记录字面 `VERDICT`。
