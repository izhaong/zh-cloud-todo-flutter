## 取舍（拿不准时按推荐方案，代价写在这里）

1. **标签名以空白终止**：`#写周报 明天` ⇒ 标签「写周报」＋正文「明天」。
   嘀嗒的标签名可以含空格，但 token 模型只能按空白切；含空格的名字用 sheet 里的新建行（FR-2）建。
   代价：`#` 路径建不出带空格的名字。
2. **同名精确匹配、不做大小写折叠**：`name.trim()` 后**逐字**比对已有标签。
   中英混排时折叠大小写会把「iOS」与「ios」并成一个，不是嘀嗒的行为。
   `todoTags` 无 name 唯一索引（`app_database.dart` 只有 `primaryKey => {id}`），
   库里已存在的同名多行取 `getAll()` 顺序（`createdAt` 升序）的第一条 ⇒ 与标签页列表显示的先后一致。
   代价：库里已有的重名标签不会被这次合并。
3. **多行快速添加共享同一批 `#` 标签**：`createBatch` 按行切任务，`#` token 在整段输入里解析一次，
   结果挂到这一批创建出来的**每个**任务上——与按钮所选标签的既有行为一致。
   代价：做不到"第 2 行单独挂 #A、第 3 行挂 #B"。真要按行挂，得改 `createBatch` 的返回契约，那是另一轮。
4. **解析放在组件层，不放进 `createBatch`**：仓储层的职责是"一行一个任务"，往里塞标签语法会让
   `TaskQuickAddSheet`／时间线拖拽这些**没有标签 UI** 的创建路径也悄悄吃 `#`。
   代价：新增创建入口时要显式再接一次（已用测试钉住"未接线就不吃 `#`"这条，见 tasks.md 探针）。
5. **`#` 不自动补全候选列表**：帮助页文字只承诺"输入「#」快速创建标签"，配图（cdn.dida365.cn）在离线镜像里
   取不到 ⇒ 无法证实嘀嗒此处是否弹候选菜单。本轮做**可见预览**（输入框下方列出这批将添加的标签），
   不做打字即弹菜单。代价：候选匹配 UX 若确有其事，属另一轮补。
