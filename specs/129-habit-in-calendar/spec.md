# 129 · 习惯打卡进日历（矩阵 #45 面 ③：「显示习惯」开关 + 日历时间轴显示习惯）

## 背景

嘀嗒《02-功能指南/05-习惯打卡/02-更好地完成习惯.md》:43/:48/:116：

> 习惯打卡也能在日历中显示；在日历视图右上方「···」-「显示设置」中开启
> 「显示习惯」，习惯就会出现在日历时间轴上。

本端日历只有任务——矩阵 #45 面 ③（习惯数据统计/日历显示习惯）。

## 设计（复用优先，零契约变更、零迁移）

- 开关挂进 specs/125 的 `CalendarInfoFlags`（`showHabits`，valueJson 通道
  同 showLunar/showHolidays，旧数据无键按关）。
- 数据：`calendarHabitDotsProvider`（autoDispose 按月）——每习惯
  `stats(period: 'MONTH')` 的 `dailyCounts` 聚合成 {日期: [(名字, 颜色, 次数)]}；
  单习惯失败不拖垮整月。
- 渲染：月视图日格在农历行之后、任务列表之前，按 `habit.color` 着色的
  习惯行（多次打卡显示 ×N）。

## 目标（FR）

- FR-1 「设置 → 日期与时间」出现「显示习惯打卡」第三开关，双键独立持久化。
- FR-2 旧数据（无 showHabits 键）按关处理。
- FR-3 月视图在开关开启时渲染习惯打卡点；provider 失败按无数据渲染，
  日历主体不受影响；关闭时不请求不渲染。

## 验收（AC）

- AC-1 仓储三键独立保存/回读；旧数据降级。
- AC-2 设置页三行可见。
- AC-3 直泵 CalendarView + showHabits 开启：日历主体照常渲染、无异常
  （provider 失败路径现状锁；着色渲染由 habit.color 纯数据驱动）。
- AC-4 门禁：analyze 0 issue、全量不回归。
