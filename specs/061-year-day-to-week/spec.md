# 061 — 年视图点击日期跳周视图并高亮所选日期

## 判据源

嘀嗒帮助中心《02-功能指南/02-日历/03-年视图：查看年度任务完成情况.md》`:64`
逐字：「点击日期 → 跳转至周视图，并高亮显示所选日期」。

复算命令（镜像在 zh-cloud-docs 仓内，路径以 `origin/develop` 为基准）：

```bash
git -C zh-cloud-docs show origin/develop:todo/99_参考资料/dida365-help-center/02-功能指南/02-日历/03-年视图：查看年度任务完成情况.md | sed -n '60,70p'
```

## 面

| 面 | 原文主张 | 本规格要落的行为 |
| -- | -------- | ---------------- |
| ① | 「点击日期 → 跳转至周视图」 | 年视图里的日格接受点击；点后视图模式变为周视图，且周视图覆盖的那一天就是被点的那天 |
| ② | 「并高亮显示所选日期」 | 周视图把被点的这天标成选中：视觉高亮 + 读屏「已选中」语义，二者同属一个带 key 的节点 |

## 范围裁定

本仓年视图按「日」呈现的表面只有热力图日格（同一帮助页 `:74`「年视图支持以热力图
方式展示任务完成频率」、`:76`「默认情况下，热力图为关闭状态，可在显示设置中手动
开启」），所以 ① ② 两面的入口都落在日格上；月视图日格的「点日 → 日程视图」是矩阵
另一面，本规格不碰。

## 不做

- 后端契约变更：本面纯客户端，`/app-api/todo` 的请求与响应字节不变。
- 新增第三方依赖。
- 周视图非选中列的外观变更：高亮只在由年视图点进来时出现，保住既有 golden 基线。
