# Todo 日历显示设置（第一批：显示已完成）

状态：进行中（2026-09-22 立项）
来源：嘀嗒《02-功能指南/02-日历/06-日历显示设置.md》「其他显示选项」；对照矩阵 #31。

## 现状（实地核对，2026-09-22）
`CalendarView` 的 `tasks` 直接来自 `TaskRepository.watchAll()`（`home_shell.dart:766-774`），
而 `calendar_view.dart` 全文对 `TodoTask.completed`（`app_database.dart:74`）**零消费** ——
已完成任务无条件出现在月/周/年/列表/日程五种模式里。嘀嗒的默认行为是隐藏，
由日历「显示设置」里的「显示已完成」开关控制。

## 需求
- FR-001 默认不渲染 `completed == true` 的任务，五种模式一致。
- FR-002 工具栏提供「显示设置」入口，其中含「显示已完成」开关；术语跟随嘀嗒，不自造同义词。
- FR-003 开关与视图模式存同一行偏好（`calendar_view` / `task_calendar`），重启后恢复；
  写失败时**保留当前已生效的状态并给出提示**，不得静默回滚界面。
  恢复本身是异步的：**读偏好期间用户已经改过视图或开关时，迟到的旧值必须作废**，
  否则表现为「刚点的档位被弹回上一次的选择」。
- FR-004 入口与开关具备独立可读屏语义；320px 宽 + 1.3 倍字体下无布局溢出。
- FR-005 清单页里的日历视图（`tasks_by_list_page.dart:453`）**不叠加**本开关：那里的已完成显隐
  已由清单筛选（`applyTaskFilter` 的 `filter.completed`，`:2023`）决定，再叠一层会把「只看已完成」
  筛出的结果清空；既然开关在那个上下文没有可见效果，「显示设置」入口一并不渲染。

## 边界（不在本切片）
- 嘀嗒的「显示已完成」原文管**三类内容**：「已完成的任务、打卡和订阅的日历事件」。本切片只接**任务**这一类；
  习惯打卡与倒数纪念日目前根本不进日历（`home_shell.dart:766-774` 只喂任务），属 #31 后续门槛，
  不得在本切片用假数据凑数。
- 颜色、类型图标、现代/经典样式、辅助时区、显示范围（清单筛选）、农历、节假日调休 —— 属 #31 的后续门槛。
- 已完成项在开启后的可辨识呈现（删除线/次要色）属下一个门槛；本切片只保证「默认隐藏 + 可开启 + 持久化」。
- 外部订阅日历事件无 `completed` 语义（`home_shell.dart:760-779` 映射时恒为未完成），不受本开关影响。
- 不改后端、不新增接口、不重录 golden 基线（若 golden 因此变化，停下上报）。
