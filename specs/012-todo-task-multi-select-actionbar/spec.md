# 012 Todo 任务多选与批量操作栏

## 目标

在不改变现有 Todo 工作区骨架的前提下，为任务列表补齐桌面端连续多选、离散多选和高频批量操作，并保留移动端可发现的显式批量编辑入口。

## 交互契约

- `Cmd/Ctrl + 点击` 切换单个任务的选中状态，并自动进入批量模式。
- `Shift + 点击` 以最近一次选择锚点为起点，按当前可见排序选中包含首尾的连续区间；锚点失效时只选择当前任务。
- 批量模式内普通点击继续切换单项选择；退出批量模式或切换视图后清理选择和锚点。
- 原有“排序与批量编辑 → 批量编辑”入口保留，确保触屏和无键盘场景可用。
- 批量模式禁用列表拖动排序与滑动手势，避免选择手势和任务变更冲突。

## 操作栏契约

- 选中任务后，在任务内容区底部显示紧凑的浮动选择坞，不挤压工作区标题栏。
- 选择坞显示已选数量、退出、完成、截止日期、优先级、移动清单、安全删除和更多操作；更多操作包含批量分享。
- 宽屏显示图标与文字，窄屏保留图标、Tooltip 和可访问语义，不出现横向溢出。
- 动效复用 `TodoLayoutTokens.stateTransitionDurationFor`，遵循系统减少动态效果设置。
- 删除为危险操作，必须二次确认；确认文案说明子任务会一并删除。

## 数据契约

- 日期、优先级、清单、标签、完成和置顶继续通过 `TaskBatchEditRepository` 执行并保留逐项结果反馈。
- 删除复用 `TaskRepository.delete` 的级联删除与 outbox 契约，不在页面复制数据库写入逻辑。
- 批量删除部分失败时，仅保留失败任务的选中状态，并提供重试入口；成功任务立即从本地列表和同步 outbox 反映。
- 批量分享按当前列表实际可见顺序生成一份文本：首行说明任务数量，每项依次包含序号、标题、非空正文和可选截止时间；通过 `NativeIntents.shareText` 打开系统分享，主题包含任务数量。
- 批量分享是纯读操作，不修改任务、不写 outbox、不退出批量选择；平台通道缺失或拒绝分享时保留选择并显示“当前设备不支持系统分享”。

## 验收

- Widget 测试覆盖 `Cmd/Ctrl` 离散多选、`Shift` 连续多选、显式入口、窄屏操作栏、批量分享顺序/文本/失败反馈和危险删除确认。
- Repository/Widget 测试证明批量删除使用既有级联删除与 outbox 行为。
- Dart MCP 静态分析、定向测试、全量测试和 Web release 构建通过。
