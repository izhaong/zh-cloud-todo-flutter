# 128 · 调整四象限顺序（矩阵 #36 面 ⑦）

## 背景

嘀嗒《02-功能指南/03-四象限/02-如何编辑四象限规则.md》:64-:75：

> mobile：点击右上角「...」，选择「编辑」，选中需要更改顺序的象限，拖动调整即可。
> desktop：点击单个象限直接拖动调整即可。

本端四象限 2×2 固定 Q1/Q2/Q3/Q4 布局——矩阵 #36 面 ⑦。

## 设计（复用优先，经 cursor-agent 交叉验证取方案 A）

- 可见状态就是 q1..q4 的一个四元排列 ⇒
  `TaskWorkspacePreference.quadrantOrder`（valueJson 通道同
  quadrantTaskSort；缺省 [q1,q2,q3,q4] 现状锁；非法排列读侧回退默认）。
- desktop：拖象限头到另一象限 ⇒ 两格交换（`Draggable<Quadrant>` +
  `DragTarget<Quadrant>`，载荷不同型不与「拖任务换象限」抢手势）。
- mobile 同一持久化：「…」菜单内「上移/下移」按阅读顺序换位（边界禁用）。

## 目标（FR）

- FR-1 排列驱动 2×2 渲染；交换/上移下移即存即生效（saveQuadrantOrder）。
- FR-2 非法排列（非四元排列）写入被仓储拒绝（ArgumentError），读侧降级默认。
- FR-3 无回调时全部入口不渲染（现状锁）。

## 验收（AC）

- AC-1 默认排列渲染（Q1 左上、Q4 右下）。
- AC-2 排列 [q3,q4,q1,q2] 时 Q3 出现在第一行。
- AC-3 desktop 拖头换位回调新排列。
- AC-4 「…」上移/下移按阅读顺序换位且边界禁用。
- AC-5 页面级：拖换后偏好落库。
- AC-6 仓储：非法排列被拒、合法落库回读。
- AC-7 门禁：analyze 0 issue、新用例全绿 + 探针、全量不回归。
