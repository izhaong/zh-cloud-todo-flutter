## 需求与裁定

1. **持久化复用既有通道**：`todo_view_preferences` 的 `SIDEBAR_VISIBILITY`/`global` 行 + `viewPreference` outbox（specs/102/103 已在用），键名 `module.<枚举名>`（`module.quadrant` / `module.pomodoro` / `module.search`），与 `smartList.` 同一套「缺键=默认」读法。不新增表、不 bump `schemaVersion`。
2. **默认「开」**：这三档在 develop 上一直是常驻可达的；默认值等于改造前行为 ⇒ 黄金基线一张都不用重录。
3. **设置页**：新增「功能模块」分区（在「智能清单」之后、「主题」之前），三档各一行，弹层选项用嘀嗒的词「开启 / 关闭」（不是标签/过滤器那套「显示 / 隐藏」，因为源页说的是启用）。
4. **入口 gating 必须可见地生效**（不是"页面上多一行字"）：
   - 四象限关闭 ⇒ 视图档位菜单不出现该档；已停在象限的（偏好异步读回）当场回落列表。
   - 番茄专注关闭 ⇒ 侧栏底部 dock 那枚「番茄」不渲染；「习惯」「倒数日」不受影响（源页没把它们列为模块）。
   - 搜索关闭 ⇒ 壳层 AppBar 搜索入口不渲染，且 ⌘/Ctrl+K 快捷键不再通向搜索页。
5. 仓储写单键只 patch 自己那键（与其它档共用同一行，整块覆盖会顶掉用户没碰的开关）。

## 诚实登记

- 本端把「功能模块」放在设置页的一个分区里，不是嘀嗒桌面端"点头像进设置"的那套层级；措辞按 `:24`/`:33` 照抄「功能模块」「开启」。
- 矩阵 #39/#41（番茄专注）与 #14（列表视图/搜索）等行的其它残面不在本单，本单只兑现"开关存在且入口随之消失"这一面，不预支那些行的状态。
- 移动端搜索：嘀嗒 :12 说"底部 tab 栏"，本端搜索入口在壳层 AppBar 右上角（develop 既有形态）⇒ 位置是形态偏差，开关这一面已齐；偏差写在这里，不写成一致。

## 测试与探针

- `test/features/settings/feature_module_settings_test.dart` 7 例：仓储默认与单键 patch（含"不许顶掉标签/其它档"）、outbox 一条且 payload 带 `module.pomodoro`、设置页三档渲染 + 看板不许出现、点「关闭」落库并显示回「关闭」、四象限档位菜单负向（同一测试里先跑正对照）、番茄 dock 负向（习惯仍在）、搜索入口负向（移动视口，正对照在前）。
- 变异探针：⑨档位菜单过滤条件去掉（`showQuadrantView` 恒 true）→ 四象限负向红；⑩dock 条件去掉 → 番茄负向红；⑪`saveFeature` 改成整块覆盖 → 仓储第一条红；⑫搜索条件只删入口不拦快捷键 → 该断言另计（本单没为快捷键单独写用例，只在实现里加了早退）。
