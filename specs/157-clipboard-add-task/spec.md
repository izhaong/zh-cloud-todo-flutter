## 改动

1. **判定做成纯函数** `suggestTasksFromClipboard`（`lib/features/task/clipboard_task_suggestion.dart`）：
   空/空白 ⇒ `null`；**≥2 行** ⇒ `multiple`（每行一条，空行不算）；1 行且**能识别出时间** ⇒ `single`
   并回显命中的那段；1 行但**识别不出** ⇒ `null`。
2. **落库那一半** `runClipboardAddTaskFlow`：读设置 → 读剪贴板 → 判定 → 按类型弹那句（逐字）；
   点「添加」按 `tasks` 逐条 `create` 到收集箱。
3. **开关** `ClipboardAddTaskSetting`（`SharedPreferences`，**默认关**）+ 设置页「任务」分区里一个
   `SwitchListTile`；冷启动在 `app.dart` 的 post-frame 里调起。

## 三处**有意的**取舍

1. **多行那一支不要求时间信息**：原文把"多行"当成独立的一条路（`:273` 没提时间）——
   要求了的话，「复制三行待办」这种最典型的用法反而不弹。
2. **开关存本机、不同步**：读剪贴板是**这台设备**的行为；同步过去会让新设备在用户没同意时读剪贴板。
3. **标题原样落库**：不改写用户粘进来的原文（时间信息交给既有的标题解析）——
   改写了用户就不知道自己建的是什么。

## 判据

| 判据 | 对哪句原文 |
| --- | --- |
| 空 / 只有空白 ⇒ 不问 | `:269`「无内容」 |
| 一行含「明天下午3点」⇒ 单条 + 回显命中段 | `:264` |
| 一行**无**时间信息 ⇒ 不问 | `:269`「无可被识别的信息」 |
| 多行（含空行）⇒ 多条，每行一条、空行不算 | `:273` |
| 多行**不要求**时间信息 | `:273` |

**反向探针**（两条各自独立验过）：
- 去掉"识别不出就不问" ⇒ `:269 无可被识别` 转红；
- 让多行也要求时间 ⇒ `:273 不要求` 转红。

## 边界

- 设置项的**位置**与嘀嗒不同：它放「设置」-「高级选项」，本端设置页分区是 账号 / 任务 / …
  ⇒ 放在「任务」里。这是**位置差异**，不是术语差异（名字逐字用它的），已在代码里写明。
- 平台侧（Android/iOS 的系统级"复制后自动建任务"）不在本切片：本切片只做**打开应用时**读一次，
  与原文 `:264`「打开应用后…询问」一致。
