## 设计决定与取舍

1. **注册表是唯一事实源**（`lib/core/shortcuts/todo_shortcut_registry.dart`）。
   工作区的 `Shortcuts` 映射与对话框里的列表都从 `todoShortcutBindings` 生成 ⇒ 界面永远不会列出
   一个其实没绑定的键位（被否方案：对话框另写一份文案清单——会漂移，正是这种清单最容易说谎）。
2. **`?` 同时绑两种 activator：`slash + shift` 与 `CharacterActivator('?')`。**
   实测：`LogicalKeyboardKey` 里**没有** `questionMark` 这个常量（`packages/flutter/lib/src/services/keyboard_key.g.dart`
   只有 `slash` 等），`?` 是 Shift+/ 打出的字符。但"这次按键以什么形态到达 Flutter"分平台不一样：
   Windows/Linux 常给 `slash` 逻辑键 + shift 修饰，macOS 与 Web 常直接给字符 `?`。
   只绑前者在部分平台上打不出来，只绑后者在另一些平台上打不出来 ⇒ 两种都绑，
   **展示仍统一写 `?`**（照抄嘀嗒那句「输入「?」」，由 `todoShortcutRows` 去重，界面上只出现一次），
   不显示成 "Shift+/" 那种工程口吻。被否方案＝只绑 `slash+shift`：本机测试会绿，
   但那是"测得到的那条路径绿"，不等于用户按得出来。
3. **裸键在输入框里必须让位给文字输入。**
   `Shortcuts` 的事件从最深焦点往上冒泡，`EditableText` 对字符键返回"不处理" ⇒ 祖先的 `Shortcuts` 会把它消费掉，
   用户在搜索框里就打不出 `?`。用 `Shortcuts.manager` + `TodoShortcutManager`（继承 `ShortcutManager`）在
   `handleKeypress` 里判：无 Ctrl/⌘/Alt 且当前焦点落在 `EditableText` 内 ⇒ 返回 `ignored`。
   带修饰键的组合（⌘K）不受影响——它不会是用户想打的字。
4. **界面只做一个：对话框。** 被否方案＝再做一个独立"快捷键页"：嘀嗒三个入口展示的是同一份列表，
   多一份布局就多一份溢出/语义/测试面，且设置页里塞一页会让返回栈变深；
   入口（设置项、`?`）都调 `showKeyboardShortcutsDialog` ⇒ 一份实现两处复用。
5. **不重录黄金基线**：新增的是浮层与设置列表里的一行，9 张黄金图覆盖的工作区版面未变
   （`flutter test --tags golden` 复跑为准，见 tasks.md）。

## 范围外（本轮明确不做，勿顺手做）

- **指令菜单（⌘K/Ctrl+K → 前往各功能模块）**：本端 ⌘K 已被"打开全局搜索"占用且有既成用例。
  照抄嘀嗒就得抢键，会把一个已验收行为换成另一个；键位归属要在"指令菜单"那一轮一起定
  （倾向：⌘K 让给指令菜单、搜索作为面板里的第一条命令），届时单独开规格。
- **修改快捷键**（嘀嗒 `:26`「在设置里查看快捷键界面，可以修改」、`:29`「显示为灰色的快捷键不能修改」）：
  需要键位重映射的持久化、冲突检测，且"哪些可改"在帮助页只有截图 ⇒ 拿不到可改集合，硬做＝自造规则。
- **侧边栏入口**（嘀嗒 `:27`「在侧边栏打开快捷键界面，可以修改」；另见 `09-桌面快捷操作.md:23` 的桌面端底部「？」入口）：会改可见布局 ⇒ 需先申请重录 9 张黄金基线。

## 验收标准

- Given 工作区已渲染且焦点不在输入框，When 按 `?`，Then 出现「键盘快捷键」对话框，
  内容与 `todoShortcutBindings` 逐条一致（动作名 + 键位文案）。
- Given 焦点在搜索框/任意输入框，When 按 `?`，Then 不出现对话框（`?` 让位给输入）。
  注：**字符真能打进文本框**这一条本地测不到 —— `flutter_test` 的 `sendKeyDownEvent` 不驱动 TextInput 的
  `onKeyText` 通道。用例只钉"守卫认出正在编辑 + intent 未被 invoke"，不声称验过字符插入。
- Given 设置页，When 点「键盘快捷键」，Then 打开同一对话框。
- Given 320px 宽 + 1.3 倍字体，When 打开对话框，Then 无溢出异常。
- Given 读屏开启，When 打开对话框，Then 标题与每一行动作名都是独立语义节点。
- ⌘K/Ctrl+K 打开全局搜索的既成行为不回退。
