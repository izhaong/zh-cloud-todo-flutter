# 127 · 四象限每象限任务排序（矩阵 #36 面 ⑪）

## 背景

嘀嗒《02-功能指南/03-四象限/02-如何编辑四象限规则.md》:135-:136：

> 如何调整四象限的任务顺序？
> 选择需要更改的象限，点击右上角「...」-「排序」，可选择排序方式。

本端象限内任务保持分桶输入顺序，无每象限排序菜单——矩阵 #36 面 ⑪。

## 设计（复用优先，经 cursor-agent 交叉验证取方案 A）

- **排序档直接复用** `TaskSort` 七档与 `compareTodoTasks` 比较器（列表视图
  同一把尺），分桶后对桶内排序；不新造排序器。
- 偏好按象限存：`TaskWorkspacePreference.quadrantTaskSort`（q1..q4 →
  `TaskSort.name`，valueJson 通道同 timelineColorBy）；缺档保持输入顺序
  （现状锁）。
- 每象限头「…」菜单（key `quadrant-sort-<象限>`）只在回调接入时渲染；
  当前档带勾选标记。

## 目标（FR）

- FR-1 每象限「…」-「排序」可选七档，即选即存（patch 合并保留其它象限档）。
- FR-2 选中档后该象限任务按该档重排；未选档的象限不受影响。
- FR-3 非法档/象限名写入被仓储白名单拒绝（ArgumentError）。
- FR-4 页面级：选档 → 偏好落库 → 界面生效；失败回退所选 + 可见 SnackBar。

## 验收（AC）

- AC-1 默认无入口、输入顺序；有回调出现入口。
- AC-2 选「按创建时间」回调带 (q1, TaskSort.createdAt)。
- AC-3 选中档后象限内重排（createdAt 默认 newestFirst ⇒ 晚建的在前），
  当前档菜单带勾。
- AC-4 页面级偏好落库 + 界面生效。
- AC-5 仓储归一化三条（非法档/非法象限/合法合并）。
- AC-6 门禁：analyze 0 issue、新用例全绿 + 探针、全量不回归。
