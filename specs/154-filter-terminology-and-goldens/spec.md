# 154 · 侧栏术语收口：「筛选器」→「过滤器」+ 重录 5 张 golden（原 FL #415）

## 病灶

同一功能在本仓有两个名字：

- 侧栏那一行写 **`筛选器`**（`sidebar.dart` 的 `_NavRow(label: '筛选器')`），
  落地页 AppBar 也跟着写 `筛选器`；
- 判据源嘀嗒《02-功能指南/01-任务/09-如何管理海量任务/**05-过滤器：随心所欲筛选你想看的任务**》通篇叫 **`过滤器`**
  （`:29`「确认侧边栏中是否已经开启**显示过滤器**」、`:33`「找到「**过滤器**」设置为「显示」」），
  设置页入口也叫「过滤器」。

按「术语照抄、不自创同义词」的北极星约束 ⇒ 统一到 **`过滤器`**。

## 内容

1. 全仓 `筛选器` → `过滤器`（**10 个文件**，含侧栏 label、落地页 AppBar 标题、读屏/注释与用例期望串）；
   现读 `grep -rn "筛选器" --include=*.dart lib/ test/` **0 命中**。
2. **重录 golden 基线**（这一步原本不在自主授权范围内，本轮按用户「按推荐的走」执行）。

## 重录的方法与旁证（不是"直接覆盖"）

改之前先在**未改动的基线**上量了一次，看差异落在哪儿：

| 基线 | 像素差 |
| --- | --- |
| `wide-populated` / `wide-selected` / `wide-empty` / `wide-long-content` | 各 **0.02% / 279px** |
| `compact-selected` | **0.03% / 275px** |
| `mobile-detail` / `mobile-list` / `mobile-min-long` / `tablet-list` | **未变** |

**"只有 5 张变"本身就是旁证**：另外 4 张是窄屏/平板档，**根本不渲染侧栏** ⇒
一个改在侧栏字串上的改动不该动它们，实测也确实没动。
若差异来自别处（比如某处版式被顺手改了），这 4 张会跟着变。

差异量级也与改动量级相符：`筛选器`→`过滤器` 三个字里改两个字，落在侧栏那一列的一行文字上，
279px 是那两个字形的像素面积量级。

重录后：`flutter test --tags golden` ⇒ `+9 All tests passed!`。
