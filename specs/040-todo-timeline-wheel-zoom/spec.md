# 时间线视图的 Ctrl/⌘ + 滚轮缩放

**状态**：实现完成，待复核
**创建日期**：2026-09-24
**关联 Issue**：[#298](https://gitea.zh04.com/izhaong/zh-cloud-todo-flutter/issues/298)
**矩阵行**：`dida-parity-matrix.md` #87（桌面快捷操作）

## 背景

嘀嗒《03-特色功能/09-桌面快捷操作.md:105-107》「## 缩放时间轴」原文：「想让日历时间区块更密集，或更宽松？按住 **Ctrl**（或 Mac 上的 **Command**）再滚动鼠标滚轮，即可缩放日视图或周视图中的时间轴，方便查看全天任务。」

本端时间线视图早就有缩放能力，但只有按钮：`lib/features/task/views/timeline_view.dart:502` 定义 `static const _step = 0.25`，`:614` 是「减小」（`zoom <= 0.75` 时禁用），`:632` 是「放大」（`zoom >= 1.5` 时禁用），`:87` 在 build 里再 `clamp(0.75, 1.5)` 归一化一次。缺的是嘀嗒文档里的**那一只手**：修饰键 + 滚轮。

## 落点与嘀嗒的差异（关键取舍，不掩盖）

嘀嗒那一节指的是**日历日/周视图的小时轴**。本端日历没有可缩放的时间轴：

- `lib/features/task/views/calendar_view.dart:168` 是 `enum CalendarMode { month, week, year, list, agenda }`，**没有 day 档**；
- 该文件里 `hour` 的唯一命中是 `:871` 的排序键 `(left.hour, right.hour)`（另有 `:52` 一行「锚点归零到当天 00:00」的注释，与小时刻度无关）⇒ 日历里没有任何小时刻度布局。

所以嘀嗒那一面的前置能力（日/周视图带小时轴）本身就缺，不是本切片能顺手补的。本切片把嘀嗒文档里的那只手挂在**端内唯一带小时刻度的时间轴**上——时间线视图（矩阵 #16）：`day`/`week` 两档由 `:594` 的 `ButtonSegment` 切换，横向单位宽度 `:789` `unitWidth = (scale == TimelineScale.day ? 58.0 : 72.0) * zoom`，而 `:899-911` 的 `_slots()` 在 day 档确实铺出 24 个整点槽位。也就是说：嘀嗒要缩放的是日历里的那条时间轴，本端结构上最接近的时间轴住在时间线视图里，本切片缩的是它。

本文件与 plan/tasks 里所有 `timeline_view.dart` 行号以**本分支工作树**（`feat/todo-timeline-wheel-zoom`，base `origin/develop@a1d7733`）为基准；`calendar_view.dart` 的行号仍以 `origin/develop` 为基准（本分支未改该文件）。合并后若 develop 上出现新的行位移，须按最终行号复校。

被否方案：

1. **判「不做」**——白丢一个纯客户端、零布局变更、零契约变更的快捷方式；缺口不变。
2. **先补日历小时轴再挂滚轮**——那是 #28/#29 量级的新表面，会改可见布局、需要重录黄金图基线（属需授权动作），不该塞进本切片冒充嘀嗒那一面。

**矩阵口径**：#87 的「缩放时间轴」**不因本 PR 进入「已证」**。本 PR 只把第 33 轮记下的「能力已有、快捷入口未做」这半条结掉；「嘀嗒那一面 = 日历日/周视图小时轴」仍是缺口，要在 #87 里保留。

## 需求

- **FR-001**：在时间轴画布上按住 Ctrl（Windows/Linux）或 Command（macOS）+ 滚动鼠标滚轮，向上放大一档、向下缩小一档；**步长必须引用工具栏那一份常量** `_step = 0.25`（`:502`），上下限沿用既有取值 `0.75 ~ 1.5`（与 `:614`/`:632` 两颗按钮的禁用条件一致）。注：该 widget 里原本就没有 min/max 常量，`0.75/1.5` 已是 `:87` 与 `:614`/`:632` 的字面量，本 FR 不新增第四处之外的抽象，也不顺手收拢它们（见 tasks.md「仍缺」）。
- **FR-002**：已到边界时不再产生缩放回调（与按钮此时的禁用态一致：`zoom >= 1.5` 不放、`zoom <= 0.75` 不缩）。
- **FR-003**：裸滚轮与 Shift + 滚轮的行为不变——仍然只滚动画布，不得顺手改缩放。Shift 不是嘀嗒 `:107` 的修饰键（`:101` 那节的 Shift + 滚轮是「快速切换日/周视图中的日期」，本端未做，也不由本切片冒充）。
- **FR-004**：宿主没有传 `onZoomChanged`（只读嵌入态）时，修饰键 + 滚轮不得抛异常。
- **FR-005**：缩放判定必须是可单测的纯函数，且判据来自真实 `PointerScrollEvent` 路径，不是直接调私有实现。

## 非目标

- 不实现嘀嗒《快速切换日/周视图中的日期》（Shift + 滚轮）与《调整界面字号》（Ctrl + `+`/`-`）。
- 不新增可见控件、不改布局、不加持久化 ⇒ 「320px + 1.3 倍字体不溢出」与「新增独立语义」两条四件套在本切片**不适用**（没有新表面：缩放值仍由既有工具栏 `:620` 的 `'时间线缩放 ${(zoom * 100).round()}%'` 播报）；「失败保留数据」「过期响应不覆盖」也不适用（无异步）。
- 不动 Service 契约、不同步缩放值到远端。
