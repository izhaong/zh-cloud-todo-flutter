# 092 倒数纪念日分组切换：顶部分组名点击 + 左右滑动（FL #457）

## 判据源

嘀嗒《02-功能指南/06-倒数纪念日/03-管理倒数纪念日.md》「分组」小节 mobile 段：
「你可以点击顶部分组名或左右滑动页面切换分组，管理更高效，分类更清晰。」

前置（!456 已合并 `0ddeca851042`）：右上角「...」的「显示分组」开关与
倒数日/纪念日/生日/节日 四档自动分组（按服务端 `type`，客户端不自造判据）。
本单补齐该小节剩余的切换交互。

## 契约

- 开启「显示分组」后：列表顶部横排渲染**非空**各档的分组名
  （key `countdown-group-tab-<type>`，顺序固定 倒数日→纪念日→生日→节日），
  当前组高亮（bold + primary 色），`Semantics(selected:)`。
- 一次只显示一组的条目；组内仍以 `countdown-group-header-<type>` 标题开头
  （header 语义保留，label = 档名）。
- 点击分组名 → `setState` 切到那一组。
- 列表区横向 fling（速度阈值 120）：左滑下一组、右滑上一组，边界停住。
  竖向滚动仍归 ListView（横竖手势不打架）。
- 开关关闭再打开、数据刷新组数变少 → 下标就地收敛，不越界。
- 条目 type 全是未知档时退回平铺，不把已有条目藏没。
- 关闭分组时回到 !456 前的平铺形态（默认形态不变，黄金基线零 countdown
  覆盖已现量：`test/visual/todo_workspace_golden_test.dart` 9 个场景全部
  是 home_shell/任务列表/详情，无需重录——#457 里「需重录 9 张黄金基线」
  的前置是抄自矩阵行 ④ 的过期说明，属假前置）。

## 测试台账（test/features/countdown/countdown_group_test.dart，10 条全绿）

1. 右上角「...」里有嘀嗒的「显示分组」开关（既有）
2. 未开启时列表平铺，不出现分组标题（既有）
3. 开启后顶部出现分组名，默认停在第一组（改写：四档 tab 按 x 递增 + 一次一组）
4. 点击顶部分组名切换到那一组（新：tab-2 → 只见纪念日甲；tab-1 切回）
5. 左右滑动页面切换分组：左滑下一组、右滑上一组（新：fling ±320@900）
6. 分组标题用的是嘀嗒原文的四类名（既有，随形态自然适配）
7. 某一类没有条目时，顶部与页面都不出现那一组（改写：tab 与 header 双查）
8. 320 宽 + 1.3 倍字号下开关可用、分组标题在屏（既有）
9. 分组名与组内标题都是读屏节点，label 念得出分类名（改写：tab label 全量 +
   切到第 2 组后 header-2 label）
