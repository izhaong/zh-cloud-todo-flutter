# 快速添加弹窗的「从模板添加」入口

> 基准：`zh-cloud-todo-flutter@origin/develop@a1d7733`（本文件所有行号在该 SHA 上 grep 过）
> 矩阵行：#7「添加任务」的模板面 + #89「笔记与摘要」里「模板仍无入口」那一格
> （编号对照：快照表里 #6 = 任务（父）、**#7 = 添加任务**、#8 = 任务详情与编辑 ⇒ 本切片挂 #7，不是 #6）
> 嘀嗒出处：`zh-cloud-docs/todo/99_参考资料/dida365-help-center/02-功能指南/01-任务/02-任务详情.md:330-358`

## 背景（实地核对，不采信上一轮注记）

嘀嗒《保存为模板》的 spoiler《如何使用任务模板？》移动端原文（`:346`）：

> 添加任务时，点击任务输入弹窗**下方**的「...」按钮，选择「**模板**」即可从模板添加任务。

本端现状：

- 模板的**保存与应用**都已实现，但只在任务详情里：分区标题 `task_detail_pane.dart:2339`（`sh('模板')`）、
  保存 `:3559` `templates.saveTask(...)` + 提示「已保存为模板，等待同步」`:3563`、
  应用 `_apply` `:3566-3586`（`templates.taskSeed(template)` → `tasks.create(listId/title/description/priority)`）、
  列表 `:3628-3651`（`repo.watchAll()`，空态「暂无本地模板」`:3632`）。
- **快速添加弹窗里没有任何模板入口**：`task_quick_add_sheet.dart` 全文 173 行，
  只有标题 `TextField:93`、优先级 `DropdownButtonFormField:102`、取消/保存 `:128-137`。
  ⇒ 嘀嗒写在「添加任务」这条主路上的入口，本端用户走不到（详情页那个「应用」按钮要求先有一个已存在的任务）。

## 功能需求

- **FR-1** 「...」按钮出现在弹窗**下方**那一行（位置照嘀嗒原话），菜单项文案照嘀嗒叫「模板」。
  不重排既有控件：取消/保存仍靠右，新增项占行首。
- **FR-2** 选「模板」→ 弹出本地模板列表（名称 + 同步状态，复用详情页同一措辞），点某一条
  **即创建**该模板对应的任务：走已验收的 `templates.taskSeed` → `tasks.create` 这一条链路，
  **不新造第二条创建路径**；提示沿用详情页既有的「已应用模板「X」」。
- **FR-3** 创建目标 = 弹窗自己的目标（`widget.listId` 与 `widget.parentTaskId`），与手输保存同目标；
  在子任务弹窗里选模板也应落在同一父任务下。
- **FR-4** 失败保留已加载数据：`create` 抛错 ⇒ 弹窗不关、用户已输入的标题不丢、给可读错误；
  模板列表为空显示「暂无本地模板」；模板仓储不可用（未登录，provider 返回 `null`）提示「请先登录」，
  不得静默无响应（本仓已有该措辞先例 `task_detail_pane.dart:1098`）。
- **FR-5** 重复触发不产生重复数据：连点两次「添加」只创建一条任务（守卫 + 同帧双 tap 用例钉住）。
- **FR-6** 四件套：320px + 1.3 倍字体下**弹窗自身**与**模板弹层自身**的 context 都不溢出；
  「...」按钮、「模板」菜单项、每条模板行都是独立可读屏语义节点。
- **FR-7** 不改服务端契约：模板 app-api 已齐（`AppTodoSummaryAndTemplateController.java:29-65`），
  本切片纯客户端。

## 取舍与被否方案

- **被否：把模板内容预填进弹窗表单再等用户保存**。本弹窗没有「说明」字段，而 `taskSeed` 带
  `description` ⇒ 预填要么新增一个嘀嗒弹窗里不存在的输入框（改可见布局 + 自创字段），要么静默丢掉
  模板的说明。嘀嗒原文是「选择「模板」**即可**从模板添加任务」，语义本就是即刻添加，
  不需要用户再确认一次。取即刻添加。
- **被否：先做桌面端「输入框下拉」或「/」斜杠菜单**。斜杠菜单全仓 0 命中
  （`git grep -i -E 'slash|斜杠' origin/develop -- lib`），它是 #7 的独立一面；混进来会让本 PR 变大且
  需要新的输入框拦截逻辑。本切片按**移动端** IA 落「...」菜单，桌面下拉与斜杠菜单记进「仍缺」。
- **不动快速添加栏（`quick_add_bar.dart`）**：嘀嗒说的是「任务输入弹窗」，对应本端 `TaskQuickAddSheet`；
  桌面常驻栏那一条是另一个表面，改它会碰 44px 布局常量（`TodoLayoutTokens.quickAddHeight`，
  被 `test/core/theme/todo_layout_tokens_test.dart:14` 钉住）与黄金覆盖面。
- **不重录 9 张黄金图**：黄金只在 `test/visual/todo_workspace_golden_test.dart`，全仓 `test/` 内
  `TaskQuickAddSheet` 零命中 ⇒ 本弹窗不在基线画面上；门禁仍跑 `--tags golden` 证明没顺手改动别处。
