# Feature Specification: Todo 推荐任务与可靠性收口

**Feature Branch**: `feat/99-todo-reliability-closeout`  
**Created**: 2026-07-15  
**Status**: 执行中；T001–T003 本地契约与自动化证据已完成；T004 固定旅程与 T005 最终 DoD 尚未达到完整验收门槛。
**Input**: 总控 B5、Flutter #99、Service #187、Docs #55。

## Requirements

- 推荐任务覆盖最近添加、多次改期、长期未完成、即将到来；原因可见且不改原始排序。
- 推荐刷新失败必须保留上一次成功缓存并给出可见且可被读屏实时感知的恢复反馈；刷新成功后清除失败状态。同一面板的刷新必须串行化，进行中的初始化或手动刷新复用同一请求，结束后才允许下一次刷新。推荐面板、刷新按钮与各任务项必须保持独立语义节点。
- 核心 outbox 支持幂等、失败退避、重试、冲突分类和可恢复副本；Widget 只经 Repository/use-case。
- 原生增强入口不得使用演示任务或伪造任务 ID；平台能力缺失时必须可见降级且不得崩溃。
- Android 必须关闭 Flutter 默认 deep-link 接管，由原生通道单独消费且只接受 `zhcloudtodo://task/add`；冷启动链接只消费一次，热启动链接通过事件通道回传，监听器未建立时最多保留最新一条合法链接。应用主壳必须作为唯一 URI 消费者，要求唯一非空 `title`，可选 `due` 只接受有效 `YYYY-MM-DD`；合法请求复用快速收集默认值并经 `TaskRepository` 的 Drift + outbox 原子链路串行创建，非法参数与创建失败给出可见反馈。系统分享与便签参数必须拒绝空内容，便签仅在 API 34+ 且系统存在处理器时报告成功。Android 今日任务小组件必须由真实 `AppWidgetProvider` 渲染最多五项当前账号 Drift 投影，原生持久化只保存显式更新的最小标题快照，登出、无有效会话或跨账号切换时清空；Android 锁屏重要任务必须只接收最多五项已同步任务的真实服务端 ID 与非空标题，使用 ongoing 私密通知渲染标题，并提供仅含数量的公开锁屏版本。显式空快照、登出、无有效会话或跨账号切换必须清除；非法任务或 Android 13+ 未授权通知时必须失败而非伪造成功。没有设备显示证据时不得把资源编译冒充完整验收；iOS 未实现能力继续显式降级。
- 固定性能、无障碍、离线恢复、第二设备、桌面/移动和九张视觉基准均需可复现证据。
- 只有 B0–B4 全部达到门槛后才可标记 B5 或任务模块完成。
