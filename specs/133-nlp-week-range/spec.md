# 133 · 智能识别「周X / 下周X / N天后 / 大后天 / 月底」本地正则覆盖（矩阵 #83 面②）

## 背景

嘀嗒《03-特色功能/05-智能识别.md》允许用户输入这些时间短语；矩阵 #83 面②
记「本地正则覆盖面缺『周X』『下周』『月底』」。

## 内容

- `NlpDateParser.parse` 新增五个模式（插在绝对日期之后、明天之前）：
  ① `周X` / `下周X`（周X 本周内不回看、同日推下周）；② `N天后`（1..365）；
  ③ `大后天`（=3 天）；④ `月底`（本月最后一天，含非闰年 2 月）。
- 既有模式不回归：明天/今天/绝对日期/裸时间 + 优先级不互抢。

## 用例（17 条）

周X 3 / 下周X 2 / N天后 3 / 大后天 1 / 月底 2 / 不回归 4 / 优先级 2。
