# Todo 搜索范围与任务组合筛选

**状态**：设计完成
**创建日期**：2026-08-02
**关联 Issue**：[#242](https://gitea.zh04.com/izhaong/zh-cloud-todo-flutter/issues/242)
**上游规格**：`specs/007-todo-task-organize-search/`

## 背景

滴答清单的“搜索任务”在同一搜索页区分任务、清单和标签；在“任务”范围可以进一步按清单、标签、优先级和日期缩小结果。当前应用虽有本地 FTS 搜索和独立工作区筛选，但搜索页只展示混合结果，用户不能在搜索语境内限定类型或组合条件。

本切片只补齐 Flutter 离线优先搜索体验。`TaskQueryRepository` 和 Drift 是本地真相源；既有 Service `GET /task/global-search` 只维持跨端契约和 A/B 对照，网络结果不得覆盖尚未同步的本地任务。

参考：[搜索任务](../../../zh-cloud-docs/todo/99_参考资料/dida365-help-center/02-功能指南/01-任务/08-如何管理海量任务/07-搜索任务.md)。

## 需求

- **FR-001**：搜索页提供“全部、任务、清单、标签”四个可读屏范围。范围切换不得清空关键词；全部按任务、清单、标签和稳定 ID 的既有顺序显示，单一范围只显示对应实体。
- **FR-002**：仅“任务”范围显示筛选入口，支持同时选择一个清单、零到多个标签、一个优先级和一个包含式日期区间；筛选与关键词为 AND 关系，多个标签也为 AND 关系。
- **FR-003**：本地搜索以固定页长 50 条分页；结果顺序在翻页、重建页面和相同条件的重复查询中稳定。加载更多只追加下一页，不替换已显示结果；没有下一页时不显示入口。
- **FR-004**：清除筛选只清除任务范围的筛选条件，不清除关键词或范围；切离任务范围再切回时保留尚未清除的任务筛选条件。
- **FR-005**：筛选所需清单与标签从当前 Drift 本地数据读取；无结果、未登录、加载中和加载更多失败均有可理解反馈，失败时保留已成功加载的结果。
- **FR-006**：320px 宽度下范围切换、筛选、清除和加载更多均可访问且无横向溢出；范围、筛选数量和每条结果有稳定的键盘/读屏语义。

## 非目标

- 不新增或修改 Service API、SQL、sync 载荷和网络搜索调用。
- 不把“保存为过滤器”嵌入搜索页；该能力由现有工作区过滤器负责。
- 不实现模糊联想、搜索历史、语音搜索或全文远端兜底。
