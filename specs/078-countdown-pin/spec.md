# 倒数纪念日「置顶」（FL #452）

判据源逐字（zh-cloud-docs `todo/99_参考资料/dida365-help-center/02-功能指南/06-倒数纪念日/03-管理倒数纪念日.md`）：

- :64「进入倒数纪念日页面，点击右上角「...」-「置顶」，即可将这个日子固定在列表顶部，随时查看，无需翻找。」
- :204「目前只支持置顶一个倒数纪念日，其他项目将按照时间自动排序。」

## 范围

- mobile：卡片「...」菜单加「置顶」项，写入后重取列表，置顶行由服务端排在首位
- 「只支持置顶一个」是服务端不变量（service PR !315 的 `PUT /todo/countdown/{id}/pinned?value=` 在同一事务内清其余行），客户端只发一次请求，不在前端补第二次写、也不在前端排顺序
- 已置顶的卡片不再给「置顶」入口：该页没写「取消置顶」的文案与交互，按「不自创同义词或交互」的约定本轮不做取消入口（要做得先补原文或产品裁定）

## 验收

- Given 一条未置顶未归档的倒数日 When 打开该卡片「...」Then 菜单里有「置顶」
- Given 点「置顶」Then 发出 `PUT /app-api/todo/countdown/{id}/pinned?value=true` 并重取，该行进到列表首位
- Given 已置顶 A 再置顶 B Then 界面按服务端给的顺序呈现，只有 B 在顶
- Given 写入失败 Then 列表仍是上一次加载的数据，并给出「置顶失败」可重试提示
- Given 320 宽 + 1.3 倍字号 Then 「置顶」入口可点
- Given 开启读屏 Then 卡片「...」的 label 念得出「更多操作 <标题>」，菜单项文案含「置顶」
- Given 置顶后有一次迟到的列表响应 Then 不得把置顶后的顺序改回去
