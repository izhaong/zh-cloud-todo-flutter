# Feature Specification: Todo 全能侧边栏

## User Stories

### US1 - 快速定位时间任务

用户可从侧边栏直接进入今天、明天、未来 7 天和全部任务。未来 7 天只包含今天之后至第 7 天末的未完成任务，不混入历史逾期任务。

### US2 - 按树组织清单与标签

侧边栏以任意深度展示文件夹树及其清单，并独立展示标签树。异常的悬空或循环数据仍只展示一次，不能让导航崩溃。

### US3 - 快速进入效率工具

侧边栏底部固定提供番茄专注、习惯打卡和倒数纪念日入口；桌面、抽屉和窄宽度下均可访问。

## Functional Requirements

- **FR-001**: 智能清单包含收集箱、今天、明天、未来 7 天、全部、已完成和垃圾桶。
- **FR-002**: 明天徽章只统计明天自然日；未来 7 天徽章统计 `(今天, +7 天]`。
- **FR-003**: 智能清单筛选与徽章使用相同时间语义。
- **FR-004**: Flutter Drift 文件夹缓存、REST outbox 和 pull 补水支持后端 `parentId`。
- **FR-005**: 文件夹仓库支持创建子文件夹和调整父级，并拒绝本地自指与后代循环。
- **FR-006**: 侧边栏按 `parentId` 展示文件夹树和标签树；节点顺序稳定，异常数据安全降级。
- **FR-007**: 标签节点可直接打开对应标签页。
- **FR-008**: 底部效率入口具有独立可访问标签和键盘焦点反馈。
- **FR-009**: 抽屉中的标签及效率导航先提交关闭抽屉，再打开目标页。

## Dependencies

- `zh-cloud-service#226` / PR `#227` 已提供文件夹 `parentId` 契约和并发安全约束。

## Out of Scope

- 文件夹拖拽排序。
- 生产数据库迁移执行与真实环境部署。
