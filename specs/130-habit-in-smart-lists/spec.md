# 130 · 智能清单显示习惯（矩阵 #45 面 ⑤）

## 背景

嘀嗒《02-功能指南/05-习惯打卡/02-更好地完成习惯.md》:66：

> 如需在智能清单中显示习惯，可在习惯页面右上角点击管理图标，
> 选择「在“今天”、“最近7天”中显示」。

本端智能清单只过滤任务流——矩阵 #45 面 ⑤。

## 设计（复用优先，经 cursor-agent 交叉验证取方案 A + 偏好归属收紧）

- 智能清单继续只过滤 `todo_task`；习惯段挂在「今天」「最近7天」列表尾部
  （展示层聚合，不进任务表、不同步、不进 outbox——伪任务方案 B 会污染
  完成态/计数/筛选/同步）。
- 偏好**独立于面③的日历开关**：原文入口在习惯页管理图标、作用面是
  智能清单 ⇒ 单独 `HABIT_SMART_LIST/global` 偏好行（view_preference
  出箱通道，零迁移）。
- 展示条件收紧（交叉验证点）：不只 `count > 0` 的已打卡日——
  「今天属于打卡周期、尚未打卡」的习惯也在列，否则开关开了也看不到
  该打的卡。

## 目标（FR）

- FR-1 习惯页右上角出现「在“今天”、“最近7天”中显示」入口，点开切换
  落库（toggle 语义）。
- FR-2 开关开启 ⇒ 智能清单（今天/最近7天）列表尾部出现习惯段：
  当日已打卡（×N）或今天待打卡的习惯行，带打卡按钮。
- FR-3 打卡走既有 habit check-in 通道，成功后刷新段数据；失败给可见提示。
- FR-4 面⑤偏好与面③日历开关互不影响（双行隔离）。
- FR-5 无回调/关闭时不渲染不请求。

## 验收（AC）

- AC-1 仓储默认关；开/关往返一致；损坏 JSON 降级；同步入箱。
- AC-2 习惯页入口存在，切换落库（两向）。
- AC-3 面⑤偏好与面③日历开关互不影响。
- AC-4 门禁：analyze 0 issue、全量不回归。
