# 规格：任务重复频率补「每周末」档（客户端）

- 来源 Issue：izhaong/zh-cloud-todo-flutter#323；服务端前置 izhaong/zh-cloud-service#316（已由 !317 合并，tip 见该单留言）。
- 判据源逐字：`zh-cloud-docs/todo/99_参考资料/dida365-help-center/02-功能指南/01-任务/10-设置重复任务.md`
  的「- 每周末」与「固定在每周六和周日重复，适合周末的休闲计划。」

## 落地

重复频率档位表新增「每周末」，选中后本地存 `WEEKEND`、出库 payload 的 `frequency` 为 `weekend`，
并按 `WEEKDAY` 先例把命中的星期派生为周六与周日。三处必须同轮改：频率白名单、
星期派生、档位与读回文案表；缺一处即「档位可选但出库值不被接受」或「存得下但界面显示裸枚举」。

## 范围外

农历、法定工作日、自选日期的交互改动；桌面端与移动端的档位呈现差异（本轮沿用同一档位表）。
