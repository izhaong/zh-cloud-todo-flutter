# 119 · 看板「显示设置」：宽度三档 + 显示输入框（矩阵 #15 面 ⑧，FL 无单号）

## 背景

嘀嗒《02-功能指南/01-任务/08-不同的视图查看任务/02-看板视图：分类管理任务.md》FAQ：

- `:209`「电脑端看板视图支持调整宽度，有小、中、大三种尺寸供你选择。
  点击看板视图右上角『...』进入『显示设置』即可调整。」
- `:213`「在『显示设置』中，你还可以设置『显示输入框』，帮助你更快地在看板中添加新任务。」

矩阵 #15 面 ⑧ 的判据：`显示设置`/`宽度` 在 kanban_view.dart 0 命中。

## 目标（FR）

- FR-1 列宽三档：small=200 / medium=260（现值，默认档）/ large=320；
  档位存 `BoardViewPreference.columnWidth`，随既有 board_preference 的
  `columnsJson` 落库与跨端同步（不新增表/列/迁移）。
- FR-2 「显示输入框」开关（默认关）：开启后每列列头下常驻行内输入行，
  回车即按列语义建任务（priority 列带档位、分组列带 sectionId；
  轴列不给输入行）；提交后清空可连续录入；失败给可见 SnackBar。
- FR-3 入口：看板模式下「排序与批量编辑」菜单出现「显示设置」
  （`todo-board-display-settings`），非看板模式不渲染。
- FR-4 保存路径：`BoardPreferenceRepository.saveDisplaySettings` 只改这两键、
  保留列序/折叠；既有 `saveLayout`（列序保存）不得冲掉显示设置。
- FR-5 旧布局 JSON（无新键）读成默认档（中 + 不显示），不抛错。

## 验收（AC）

- AC-1 `saveDisplaySettings` 落库回读一致；`saveLayout` 后显示设置仍在。
- AC-2 三档宽度真实改变列宽（200/260/320）。
- AC-3 开关开启：输入行可见，回车提交走真实仓储并带列档位；
  未开启：无输入行。
- AC-4 页面级：看板模式菜单有「显示设置」→ 选「大」+开输入框 → 保存 → 偏好落库。
- AC-5 门禁：analyze 0 issue、新用例全绿 + 探针、全量不回归。
