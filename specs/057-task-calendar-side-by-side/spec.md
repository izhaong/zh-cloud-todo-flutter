## 三、决定

1. **锚点在左轨，不在侧栏；本单先写错、后被交叉验证纠正**。
   模块图标其实存在：`lib/features/home/todo_workspace.dart:395` 是
   `for (final item in Section.values) _RailButton(tooltip: item.label, icon: item.icon, ...)`
   ⇒ 任务 / 日历 / 习惯 / 我的 各一个图标，`tooltip` 取 `Section.label`（`section.dart:14` 的 `'任务'`）。
   侧栏那 13 行是"进了任务模块之后的视图入口"，与模块图标不是一回事。
   复算：`grep -n "for (final item in Section.values)" lib/features/home/todo_workspace.dart` ⇒ 命中 `:395`。
   ⇒ 右键挂在这两个模块图标上，**不需要改 IA**。交叉验证当时给的排序是 C > A > B，
   但三条候选都建立在"没有模块图标"这个错误前提上，名次不采用；
   采用它**独立成立**的两条：方向要进偏好（§三 2）、窄屏静默降级（§三 5）。
2. **方向是要存的事实，不是渲染时的偶然**：`:21` 与 `:31` 是**两条不同排布**（日历在右 / 任务在右），
   偏好里存「哪一侧是副模块」，不能只存布尔开关——只存布尔的话，重进工作区时无法还原
   用户当初是从哪个图标开的，两侧主从会翻转。
3. **默认关闭**：并列偏好默认「未开启」⇒ 默认态与 develop 同形，9 张黄金基线**不重录**，
   这条本身是门禁之一（`flutter test --tags golden` 必须原样绿）。
   矩阵 #32 旧格写着「属会改可见布局的一档（动 9 张黄金基线要先申请）」——本轮实测这条不成立：
   并列默认关、基线不动，读数记在 `tasks.md` 的门禁表。
4. **形态门槛是 `wide` + `compact`**：两种桌面形态都常驻左轨与侧栏，放得下两块内容；
   `tablet` 侧栏是抽屉、`mobile` 连左轨都不渲染（实测窄屏下 `find.byKey(Key('todo-rail'))` 为 0 个，
   模块切换走底部导航），故不提供并列入口。
5. **不支持态静默降级，不弹提示**：窄屏拿到已开启的偏好时画回单模块、偏好不清空，回宽屏自动恢复。
   依据是仓内既有分工——**布局档位**的降级一律静默（详情容器在 宽栏 / endDrawer / 全屏路由之间
   静默切换：`home_shell.dart` 的 `_syncLayoutProfile` 与 `_MobileTaskDetailRoute`；`README.md`
   写着窄屏「只改变导航和详情容器」）；**能力不可用**的主动操作才给可见提示
   （桌面便签失败提示、筛选器「本机暂不支持套用」）。本条属前者。
6. **切到不参与并列的模块只闸不写**：并列只在当前 `_section ∈ {tasks, calendar}` 时画副栏
   （`home_shell.dart` 的 `pairEligible` 渲染闸门），切去「习惯 / 我的」当帧回到单模块，
   切回来按记忆恢复。源页 `:39` 只给了「右键→关闭同时显示」这一条关闭路径，
   切模块顺手写 off 等于在没有用户关闭动作的情况下摧毁用户设置。
   - ⚠️ **第 1 轮复核抓到**：上一版这里写的是「落到 habit/mine 时置 off」，理由写成
     「并列会把用户刚选的习惯/我的整个遮住」——而同一份实现的 `pairEligible` 本来就不会让
     副栏盖住别的模块，**理由与本实现自相矛盾**，代码却照那句错理由写了一遍。
     已改成"只闸不写"。判据用例 `切去「习惯」再切回「任务」：并列按记忆恢复，切模块不改写偏好`
     （`test/features/home/workspace_companion_test.dart`）：改前红在写盘次数（该 1 实 2，
     第 2 次就是清偏好），删掉那段 `apply(off)` 后绿。



## 四、验收标准

- V1 右键任务侧锚点 ⇒ 菜单出现「同时显示日历」，选择后日历与任务清单**并列**，日历在**右**。
- V2 右键日历侧锚点 ⇒ 菜单出现「同时显示任务」，选择后任务清单在日历**右**。
- V3 已并列时，同一锚点的菜单出现「关闭同时显示」，选择后恢复单模块视图。
- V4 并列与方向偏好落本地库，重进工作区后仍是同一侧（由 `--summary` 之外的复算证明，见 `tasks.md`）；
  切到不参与并列的模块**不改写**这条偏好（§三 6，源页 `:39` 只给右键一条关闭路径）。
- V5 默认（未开启）时布局与 develop 逐像素一致 ⇒ golden 9 张不重录仍绿。
- V6 四件套：320px 与 1.3 倍字号在该 sheet 自己的 context 实测不溢出；菜单项读屏有独立语义；
  偏好读写失败要保留已加载的界面；过期响应不覆盖新响应。
- V7 菜单文案**只用**源页的三个词：「同时显示日历」/「同时显示任务」/「关闭同时显示」，
  不出现"分栏""双栏""并排"等自创同义词。
