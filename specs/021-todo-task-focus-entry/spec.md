# Todo 从任务入口开始番茄专注

**状态**：已合并，验证完成
**创建日期**：2026-08-02
**关联 Issue**：[#247](https://gitea.zh04.com/izhaong/zh-cloud-todo-flutter/issues/247)
**上游规格**：`specs/015-todo-focus-session-parity/`

## 背景

滴答清单官方“如何开始专注”除了专注模块和提醒弹窗外，还支持从任务列表及任务详情直接关联并开始专注。当前 Flutter 已有 `PomodoroPage(taskId: ...)`、专注模块的任务选择器和提醒弹窗入口，但任务列表及任务详情没有这条可达路径。

参考：[如何开始专注](../../../zh-cloud-docs/todo/99_参考资料/dida365-help-center/02-功能指南/04-番茄专注/01-如何开始专注.md)。

## 需求

- **FR-001**：已同步、未完成且未放弃的任务，在现有任务列表“更多”菜单中提供“开始专注”；移动端用户可通过既有的左滑“更多”触达，桌面端用户可通过右键上下文菜单或行内“更多”触达。
- **FR-002**：任务详情的窄屏“更多任务操作”及宽屏详情“更多任务操作”提供“开始专注”，并将任务的后端整数 ID 传给 `PomodoroPage`。
- **FR-003**：未同步、已完成或已放弃的任务不得出现可执行的“开始专注”入口；不以本地 UUID 伪造后端任务 ID。
- **FR-004**：该入口只导航至现有 `PomodoroPage`，由专注页面继续完成模式选择、开始、跨端会话收敛和失败反馈；不新增 Service API、Drift schema、outbox 实体或同步载荷。
- **FR-005**：窄屏 320px 下列表菜单与详情菜单无横向溢出，所有入口有稳定文字、键盘菜单路径和读屏名称。

## 非目标

- 本切片不新建“滑动操作”偏好页；保留已有“更多”菜单作为移动端可访问路径。可配置滑动快捷操作属于后续独立能力。
- 不改变计时模式、专注记录、统计、分析、计时器或提醒派发的既有合同。
- 不将本地未同步任务排入服务端专注会话。

## 验收

- Widget 红绿测试覆盖桌面右键列表菜单、移动端既有更多菜单、任务详情窄屏/宽屏菜单和 serverId 传递。
- 测试覆盖未同步、已完成和已放弃任务不展示入口。
- `dart format --output=none --set-exit-if-changed`、`flutter analyze`、相关测试、全量 `flutter test` 和 test 配置 Web release 成功。
- Claude CLI 对本规格、任务行/详情入口与测试给出明确 `VERDICT`；若 CLI 无输出或失败，保留原始阻塞证据而不冒充通过。
