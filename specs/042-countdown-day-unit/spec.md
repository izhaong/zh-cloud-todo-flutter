## 用户故事
作为记录正数日的人，我在倒数日卡片上点那个数字，就能从「已经 2000 天」换到「5 年」「285 周」再换回来，
因为 2000 天这个数字本身看不出有多长。

## 功能需求
- **FR-001** 倒数日列表每一行的天数文案可点击，点击后在天 → 年 → 周 → 天 之间循环。
  源页 `:97` 只规定「在**天、年、周**三种单位间快速切换」这一**单位集合**，没有规定顺序，也没有说要点几次回到原档 ⇒ 循环顺序（按 `:97` 列举次序排）与「第四次回到天」是**本端实现选择**，不是嘀嗒的要求。
  - **FR-001a（以代码为准的补条，2026-09-24 写回）** 单位入口只在「那一行中间真的有天数值可点」时给出：
    正数日且 `showAge == false` 时该行显示目标日期（`countdownDateSubtitle`），此时**不塞按钮**——源页 `:97` 说的是
    「点击中间的天数」，中间没有天数还挂个按钮就是自创交互。落点：`countdown_page.dart` 的
    `final showDays = item.isCountUp ? item.showAge : true;`（`CountdownDto.showAge` 后端默认 false，
    `efficiency_api.dart:299`）。倒数日（`daysRemaining < 0`）恒给入口。
  - **FR-001b** 写回进行中（页面 `_writePending`）时该行不可再点：`onTap` 传 null，沿用 develop 对整行
    编辑/删除按钮的同一套门控，不自创第二套。
- **FR-002** 单位换算：年 = 天数整除 365，周 = 天数整除 7；只给整数档，不凑「几年几个月」这种源页没写的写法。
- **FR-003** 前缀取源页用词：正数日是「**已过** N 天 / 已过 N 年 / 已过 N 周」，倒数仍是「还有 …」。
  依据《01-添加倒数纪念日.md:106》「系统会自动显示距离该日期**已过**/还有多少天」。
  ⚠️ **本条以代码为准修订过**：初稿写的是「**已** N 天」并声称「前缀不变」，`ed53c8c` 已改成源页词「已过」，
  旧措辞不成立（`countdownCountLabel` 返回 `'${isCountUp ? '已过 ' : '还有 '}$amount ${unit.suffix}'`）。
- **FR-004** 按行独立：一行切到「年」不影响其它行。
- **FR-005** 读屏能单独够到这个天数块：该块的 semantics 节点带 `isButton` 标志，label 为
  「切换天数单位 + 当前单位文案」（`label: '切换天数单位 $label'`）。
  ⚠️ **措辞以代码为准**：不是「label 就等于当前文案」——`bySemanticsLabel(RegExp('还有 1095 天'))` 靠的是
  label 后半截命中，前缀是动作说明，读屏用户先听到「切换天数单位」再听到当前值。
  实测：`InkWell` 单独**不会**置 `isButton`（摘掉外层 `Semantics(button: true)` 后该断言即红），所以这层包装是必要的，不是装饰。
- **FR-006** 320px 宽 + 1.3 倍字号下三档都能渲染且不溢出。

## 取舍与被否方案
- **落点选列表卡片（`:106` 桌面那一档）而不是详情页（`:97` 移动那一档）**：本端 `lib/features/countdown/` 只有
  `countdown_page.dart` 单文件 117 行（基线 `a1d7733`，本轮分叉点，复验 `git show a1d7733:lib/features/countdown/countdown_page.dart | wc -l` = 117；该基线上 `样式` 0 命中），没有任何详情页；先补详情页等于自创信息架构（嘀嗒的详情页还带样式/备注，
  那些面本 spec 不负责）。因此移动端 `:97` 那一档**仍未满足**，记在「仍缺」。
- **否掉「长按弹菜单选单位」**：源页只说「点击…切换」，没有任何弹层，加了就是发明交互。
- **否掉「把单位选择持久化（SharedPreferences / 契约列）」**：源页没说要记住，契约也没这一列；会话内状态是
  最小实现，持久化属另一面。
- **否掉「年显示为 5 年 5 个月」**：源页 `:93` 问的是「这是多少年，或是多少周」，整数档即可；带余数要自创格式。
- 优先「不改侧栏/dock、不新增 push 路由」的落点（objective 决策规则），本面正好满足：只改一行的 subtitle。

## 四件套自查
| 要求 | 结论 |
| --- | --- |
| 320px + 1.3 倍不溢出 | FR-006 有用例，且档位作用在 `CountdownPage` 自己的 context 上（`Builder` 包在 `home:` 之下、页面之上），不是只包 `home:` |
| 独立可读屏语义 | FR-005：天数块自己的 semantics 节点，`isButton` + label「切换天数单位 + 当前文案」；句柄 `try/finally` 释放 |
| 失败保留已加载数据 | 本面无异步动作（纯本地 setState），不适用；不谎称已证 |
| 过期响应不覆盖新响应 | 同上，本面无网络请求，不适用 |

## 不做
- 不做样式选择器、不做颜色、不做图片上传、不做备注（都要么缺契约、要么会改可见布局需先申请重录黄金基线）。
- 不做「年/周」的小数与余数展示。
