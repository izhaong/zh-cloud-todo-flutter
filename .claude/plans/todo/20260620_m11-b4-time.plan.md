# M11-B4 时间+效率（通知 + 番茄/习惯/倒数日）— 实施计划

**目标**: zh-cloud-todo-flutter 仓 `feat/m11-b4-time` 分支（base: main 7b96bef）。在 M11-B3 视图 5 tab 之上，新增 3 类"时间 + 效率"工具：番茄钟（Pomodoro）、习惯打卡、倒数日 + 本地通知接入。

**根**: `/Users/zhonghao/Code/zh-cloud/zh-cloud-todo-flutter`

## 关键设计

### 1. 顶层入口：home Tab 调整
- 当前 home 已有"任务" tab（M11-B1/2/3）
- M11-B4 新增"效率" tab（"任务"/"效率"/"我的" 3 tab），效率 tab 内 TabBar 切换：番茄 / 习惯 / 倒数
- 任务 tab 仍由 `TasksByListPage` 渲染（包含 5 视图）

### 2. 番茄钟 (Pomodoro)
- 简单 Timer-based 计时器（25/5/15 三档：focus / short break / long break）
- Drift 新表：`pomodoro_session` (id, startAt, durationSec, type, completed, taskId?)
- UI：圆环进度 + 大字倒计时 + 开始/暂停/重置
- 完成时弹 Snackbar 写入一条 session
- Provider 持有 `Timer` 状态（不持久化进行中的计时）

### 3. 习惯打卡 (Habit)
- Drift 新表：`habit` (id, name, color, icon, targetPerWeek, archived, serverId?, ...)
- Drift 新表：`habit_log` (id, habitId, date [yyyy-MM-dd], count, createdAt)
- 列表：每个习惯一行，今日是否已打卡（圆点）+ 连续天数（streak）
- 点击 toggle 今日打卡（写入 habit_log）
- 计算 `streak` 纯函数 `computeStreak(List<habit_log>) -> int`

### 4. 倒数日 (Countdown)
- Drift 新表：`countdown` (id, title, targetAt, color, archived)
- 列表：标题 + 距离天数（大字）+ 颜色 chip
- 增删改：长按删除 / 标题点编辑
- 纯函数 `daysUntil(DateTime target, DateTime now) -> int`（已过返回负数）

### 5. 本地通知（精简）
- 引入 `flutter_local_notifications` 包（最小化依赖：仅通知）
- Android 13+ 申请 POST_NOTIFICATIONS 权限
- 番茄完成 → 立即发一条本地通知
- 倒数日 提前 1 天 0:00 提醒 → 用 `zonedSchedule`（需 `timezone` 包 + `flutter_native_timezone` 或 `flutter_timezone`）
- iOS 后台调度不在本批范围（注释说明）
- 通知初始化在 `main.dart` 启动期一次性调用

### 6. Provider 复用
- `appDatabaseProvider` (M11-B1)：直接复用
- `habitRepositoryProvider` / `pomodoroRepositoryProvider` / `countdownRepositoryProvider` 新建，遵循 M11-B2 的 `Repository extends ... ` 模式
- `notificationServiceProvider`：单例 service

## 风险 / 简化项

1. **iOS 后台调度**：本批只做 Android 调度；iOS 注释说明需后续配合 APNs。
2. **精确 0:00 提醒**：依赖系统调度时区，本批只做"提前 1 天同一时刻"提醒（zonedSchedule），不做"提前 0 点整"。
3. **权限拒绝**：POST_NOTIFICATIONS 拒绝时，UI 文案提示但不阻塞主流程。
4. **serverId 同步**：本批只本地落库；sync 钩子留 TODO（与 M11-B2 sync_queue 模式对齐后续 B 接）。
5. **habit targetPerWeek 进度可视化**：本批只展示 streak，不做周完成率环。

## 不做项

- 不重写 M11-B2/B3 已有代码
- 不动后端 service
- 不引入云推送（仅本地通知）
- 不做习惯多频率（每天 / 每周 N 次）配置 UI — targetPerWeek 字段保留但不展示
- 不做倒数日重复（每年）提醒
- 不做番茄白噪音 / 提醒音配置
